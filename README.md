# A3-Jogo-Guloso

## Jogar com controle

O jogo reconhece o primeiro controle conectado. Em **Opções → Controles**, no menu inicial ou na pausa, escolha o dispositivo e a ação para mudar o comando. A configuração fica salva para a próxima partida. Os avisos acompanham o último dispositivo usado. Os botões padrão abaixo seguem o layout Xbox.

| Ação | Controle |
| --- | --- |
| Mover, direcionar o dash e navegar nos menus | Analógico esquerdo ou direcional |
| Pular e confirmar nos menus | A |
| Dash e voltar nos menus | B |
| Ataque normal / forte | X / Y |
| Trocar de arma | LB |
| Interagir e avançar diálogos | RB |
| Arremessar a arma na sala do chefe | RT |
| Pausar e retomar | Start/Menu |

Na parede, segure a direção contrária por 30 frames para se soltar, ou aperte pulo enquanto segura essa direção para saltar imediatamente para trás.
